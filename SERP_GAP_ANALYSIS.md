## Important finding: competitor title/content pattern we must NOT copy

Several competitors (rashadwahba.com, orabylaw.com, elraif.com) use superlative page titles like **"أفضل محامي مدني في مصر"** / **"أفضل محامي جنايات في دمياط"** ("best civil lawyer in Egypt" / "best criminal lawyer in Damietta"). This is a common pattern in this vertical — but per this project's own explicit rule (§4 of the governing brief, and the standing site rules), **we do not use "أفضل" / "رقم 1" / unverifiable superlative claims**, regardless of how common the pattern is among competitors. Noting this explicitly so it isn't mistaken for a content gap to copy.

## Real content-format gap observed
mohamymasr.com and rashadwahba.com both run multiple distinct pages per specialty+intent combination (e.g., a general civil-law page *and* a separate compensation-specific page *and* a separate contract-dispute page). Our site already does this structurally (42 practice areas + growing article cluster, see `CIVIL_AUTHORITY_MAP.md`) — so this isn't a structural gap, but it confirms the direction (deep, specific pages per real client need, not one generic "civil law" page) is the right one to keep investing in.
