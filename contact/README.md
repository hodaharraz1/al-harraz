# Al Harraz Contact

مشروع بسيط: QR فيه بيانات مكتب آل حراز للمحاماة والاستشارات القانونية. مفيش قاعدة بيانات، مفيش Framework — PHP + JSON بس.

## فيه QR جاهز دلوقتي، مش محتاج استضافة

`assets/qr/qr-vcard.png` — الـQR ده **البيانات نفسها متخزنة جواه مباشرة** (اسم المكتب، الأرقام، الواتساب، العنوان، الموقع، المواعيد). لما حد يعمله Scan بموبايله، هيقترح عليه فوراً "إضافة جهة اتصال" بكل البيانات دي — **من غير ما نحتاج نرفع أي حاجة على أي استضافة خالص**. نزّله واطبعه على طول.

البيانات اللي جواه دلوقتي هي البيانات الحقيقية المؤكدة من الموقع الرئيسي (الاسم، الأرقام، العنوان، رابط الموقع، المواعيد). **البريد الإلكتروني للمكتب لسه مش موجود عندنا** فسبته فاضي — لو حبيت تضيفه لاحقاً، عدّله من `admin.php` وهيتحدث الـQR تلقائي.

لو غيرت أي بيانات بعد كده من `admin.php`، الـQR بيتحدّث تلقائي كل ما تحفظ — بس **أي نسخة مطبوعة بالفعل هتفضل شايلة البيانات القديمة**، لأن البيانات متخزنة جوه الصورة نفسها. لو غيرت حاجة مهمة (رقم تليفون مثلاً)، اطبع نسخة جديدة.

## فيه كمان بديل تاني اختياري (لو حبيت الاستضافة لاحقاً)

المشروع فيه كمان نظام كامل (صفحة تواصل + لوحة إدارة) ممكن يترفع على أي استضافة عادية، وبيولّد QR **بيوجّه لرابط بدل ما يشيل البيانات جواه** — ميزته إنه لو غيرت البيانات، نفس الـQR المطبوع يفضل شغال من غير ما تطبع نسخة جديدة. ده اختياري تماماً ومش لازم تعمله دلوقتي؛ التفاصيل تحت في الأقسام 1-4.

## هيكل المشروع

```
contact/
  index.php          صفحة التواصل العامة (لو استخدمت نظام الاستضافة الاختياري)
  admin.php           لوحة إدارة البيانات (محمية بكلمة مرور) — بتحدّث data.json و QR البيانات المباشرة
  vcard.php           بيولّد ملف vCard (.vcf) لزرار "حفظ جهة الاتصال" في index.php
  config.php           إعدادات المشروع — كلمة المرور والدومين (لو استخدمت الاستضافة)
  generate-qr.php     بيولّد صورتي الـQR (البيانات المباشرة + الرابط)
  data.json            بيانات المكتب الفعلية — معبّاة بالبيانات الحقيقية بالفعل
  assets/css/          الستايل
  assets/js/           سكريبت لوحة الإدارة (إضافة/حذف أرقام تليفون)
  assets/logo/         شعار المكتب
  assets/qr/qr-vcard.png  ← الـQR الجاهز دلوقتي (بيانات مباشرة، بدون استضافة)
  assets/qr/qr.png        الـQR البديل (رابط) — بيتولد بس لو استخدمت الاستضافة الاختيارية
  assets/lib/phpqrcode/ مكتبة توليد QR (PHP QR Code — مكتبة مفتوحة المصدر، رخصة LGPL 3، موجودة كاملة مع ملف الرخصة نفسه)
```

## القسم الاختياري: استضافة صفحة التواصل الكاملة

## 1) رفع المشروع على الاستضافة

1. ارفع مجلد `contact/` بالكامل على الاستضافة (عن طريق FTP أو File Manager بتاع لوحة تحكم الاستضافة).
2. تأكد إن السيرفر شغال PHP نسخة 7.4 أو أحدث (المشروع اتعمل واتاختبر على PHP 8.4).
3. تأكد إن مجلدي `assets/qr/` والملف `data.json` قابلين للكتابة من السيرفر (صلاحيات 664 أو 775 حسب إعداد الاستضافة — أغلب الاستضافات العادية شغالة كده افتراضياً).
4. مفيش أي خطوة تثبيت تانية (مفيش composer، مفيش npm، مفيش قاعدة بيانات).

## 2) تغيير كلمة مرور الإدارة

كلمة المرور الحالية (Placeholder) هي: `ChangeMe123!` — **لازم تغيّرها قبل ما تنشر الموقع فعلياً**.

من جهازك (أي جهاز عليه PHP مثبت، أو من نفس السيرفر لو فيه SSH)، شغّل السطر ده واستبدل `كلمة_المرور_الجديدة` بالكلمة اللي عايزها:

```bash
php -r "echo password_hash('كلمة_المرور_الجديدة', PASSWORD_BCRYPT), PHP_EOL;"
```

هيطبعلك سطر زي:
```
$2y$12$abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ12
```

افتح ملف `config.php` وحط السطر ده مكان قيمة `ADMIN_PASSWORD_HASH`:

```php
const ADMIN_PASSWORD_HASH = 'الكود_اللي_طلع_عندك_هنا';
```

## 3) تحديد الدومين النهائي

في نفس ملف `config.php`، غيّر السطر ده للرابط الحقيقي بتاع صفحة التواصل بعد الرفع:

```php
const CONTACT_PAGE_URL = 'https://yourdomain.com/contact/';
```

مثال لو الموقع هيكون على `https://alharraz-contact.com/`:
```php
const CONTACT_PAGE_URL = 'https://alharraz-contact.com/';
```

بعد التعديل، ادخل على `admin.php` ودوس **"إعادة توليد QR"** عشان الصورة تتولد بالرابط الصح. الخطوة دي بتتعمل **مرة واحدة بس** — بعد كده أي تعديل في الأرقام أو العنوان من admin.php ميأثرش على الـQR خالص، وهو هيفضل شغال زي ما هو.

## 4) رابط صفحة الإدارة

بعد الرفع، لوحة الإدارة على:
```
https://دومينك/contact/admin.php
```
(أو `https://دومينك/admin.php` لو رفعت محتويات المجلد على جذر الاستضافة مباشرة بدل مجلد `contact` منفصل).

## 5) طباعة الـQR

بعد ما تولده من admin.php، هتلاقيه في:
```
assets/qr/qr.png
```
نزّله واطبعه بالحجم اللي يناسبك (على كارت العمل، لافتة، إلخ) — نفس الصورة دي تفضل شغالة للأبد طالما `CONTACT_PAGE_URL` في config.php متغيرتش.

## ملاحظات أمنية

- كلمة مرور الإدارة مش موجودة كـ Plain text في أي مكان — بس الـ Hash بتاعها.
- الجلسة (Session) بتنقفل تلقائياً بعد 30 دقيقة من عدم النشاط.
- بعد 5 محاولات دخول غلط، لوحة الإدارة بتتقفل 5 دقايق.
- كل البيانات اللي بتتعرض في الصفحة العامة أو لوحة الإدارة بتتعمل لها `htmlspecialchars` قبل العرض، وأي HTML يتكتب في الحقول بيتشال قبل الحفظ — مفيش إمكانية حد يحقن كود عن طريق تعديل البيانات.
- ملف `data.json` والملفات الداخلية (`config.php`, `includes/`, `assets/lib/`) محمية من الوصول المباشر عن طريق `.htaccess` (لو السيرفر Apache).

## مكتبة QR المستخدمة

الجزء بتاع توليد صورة الـQR بيستخدم مكتبة **PHP QR Code** مفتوحة المصدر (رخصة LGPL 3) — موجودة كاملة في `assets/lib/phpqrcode/` مع ملف الرخصة الأصلي بتاعها. الاختيار ده كان عشان نضمن إن الـQR بيتولد صح ويتقرا من أي كاميرا موبايل، بدل ما نعتمد على خدمة خارجية أونلاين بتحتاج إنترنت واشتراك.
